# Médoc Handball · pronos et stats

Site publié sur https://medochandballstats.com : pronostics, calendrier, classement et stats rigolotes des équipes de Médoc Handball (SF1, SF2, SG1, SG2, -18F1, -18F2, -18G), à partir des données publiques de ffhandball.fr.

`index.html` est régénéré et republié automatiquement après chaque mise à jour du site.
